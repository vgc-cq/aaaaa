# 任务4：智能体/数字员工雏形

## 选择方向：投流复盘助手

从6个可选智能体中选择 **投流复盘助手** 作为核心演示智能体，同时实现了其他4个辅助智能体。

## 一、投流复盘助手

### 基本信息

| 项目 | 说明 |
|------|------|
| **名称** | 投流复盘助手 |
| **使用场景** | 投流运营每日/每周复盘，快速判断视频投放效果并给出优化建议 |
| **核心价值** | 替代人工逐条分析数据，自动识别问题并生成可执行建议 |

### 输入字段

| 字段 | 说明 | 示例 |
|------|------|------|
| video_code | 视频编号 | V001 |
| content_direction | 内容方向 | 上班族40秒早餐果汁 |
| play_count | 播放量 | 12000 |
| bounce_rate_2s | 2秒跳出率 | 38% |
| completion_rate_5s | 5秒完播率 | 22% |
| completion_rate | 完播率 | 15% |
| cart_clicks | 购物车点击 | 90 |
| spend | 投流消耗 | 300 |
| revenue | 成交金额 | 712 |
| orders | 订单数 | 8 |
| feedback | 用户反馈 | 评论集中问"清洗麻烦吗？" |

### 输出字段

| 字段 | 说明 |
|------|------|
| performance_rating | 表现评级（优秀/良好/一般/较差） |
| key_metrics | 关键指标（CTR、CVR、ROI、CPA） |
| problems | 问题列表（含原因分析和严重程度） |
| optimization_actions | 优化动作列表（含优先级和预期效果） |
| decision | 投放决策（继续放量/小幅测试/停投重做） |
| next_step | 下一步具体操作建议 |

### 核心提示词

```
你是一位资深千川投流数据分析专家，擅长从数据中发现问题并给出可执行的优化建议。
请根据视频表现数据和投流数据，输出结构化的复盘分析报告。
判断标准：
- ROI>3：优秀，建议继续放量
- ROI 1.5-3：良好，建议小幅优化
- ROI 1-1.5：一般，建议观察调整
- ROI<1：较差，建议考虑停投
- 2秒跳出率>50%：钩子质量差，需重做脚本
```

### 知识库/规则来源

- 投流复盘库（K003）：ROI判断标准、异常阈值
- 历史复盘数据：过往视频的表现基准

### 测试样例

**样例1：表现良好的视频**
```json
输入：{
    "video_data": { "video_code": "V003", "content_direction": "宿舍饮品", "play_count": 20000, "bounce_rate_2s": "29%", "completion_rate": "21%" },
    "ad_data": { "spend": 250, "cart_clicks": 220, "revenue": 1602, "orders": 18 },
    "feedback": "收藏较高，评论关注价格和容量"
}
预期输出：ROI=6.41，评级"优秀"，决策"继续放量"
```

**样例2：需要停投的视频**
```json
输入：{
    "video_data": { "video_code": "V002", "content_direction": "健身饮品", "play_count": 8000, "bounce_rate_2s": "51%", "completion_rate": "9%" },
    "ad_data": { "spend": 200, "cart_clicks": 35, "revenue": 178, "orders": 2 },
    "feedback": "前3秒钩子偏弱，点击偏低"
}
预期输出：ROI=0.89，评级"较差"，决策"停投重做"
```

## 二、其他已实现智能体

### 1. 选品分析助手
- 输入：商品名称、价格、销量、口碑、类目
- 输出：选品评分、适合人群、风险点、内容角度建议、是否建议测试

### 2. 脚本生成助手
- 输入：商品名称、目标人群、场景、时长
- 输出：脚本标题、秒级分镜、发布标题、标签

### 3. 视频质检助手
- 输入：脚本内容
- 输出：总分、6维度评分、问题列表、改进建议

### 4. 客服话术助手
- 输入：用户咨询内容、商品信息
- 输出：回复话术、跟进动作、意向分析、加微话术
