# 任务5：数据复盘与自动分析

## 一、数据字段设计

### 复盘表字段

| 字段 | 说明 | 来源 |
|------|------|------|
| review_period | 复盘周期 | 手动填写 |
| product_performance | 商品表现 | 综合分析 |
| content_performance | 内容表现 | 视频数据汇总 |
| video_performance | 视频表现 | 视频+投流数据 |
| ad_performance | 投流表现 | 投流数据汇总 |
| problem_analysis | 问题归因 | AI分析+人工判断 |
| next_action | 优化动作 | 基于问题归因 |
| owner | 负责人 | 指定 |
| deadline | 截止时间 | 指定 |

## 二、关键指标计算公式

### 投流效率指标

| 指标 | 公式 | 说明 | 基准值 |
|------|------|------|--------|
| ROI | 成交金额 / 投流消耗 | 投入产出比 | >3优秀, 1.5-3良好, <1停投 |
| CTR | 点击量 / 展现量 × 100% | 点击率 | >3%良好 |
| 购物车点击率 | 购物车点击 / 展现量 × 100% | 兴趣转化 | >1%良好 |
| 成交转化率 | 订单数 / 购物车点击 × 100% | 购买转化 | >5%良好 |
| CPA | 投流消耗 / 订单数 | 单笔成交成本 | <50元良好 |

### 内容质量指标

| 指标 | 说明 | 基准值 |
|------|------|--------|
| 2秒跳出率 | 前2秒流失用户比例 | <40%良好 |
| 5秒完播率 | 看完5秒的用户比例 | >25%良好 |
| 完播率 | 完整观看比例 | >15%良好 |

## 三、异常判断规则

### 投流异常规则

| 规则编号 | 条件 | 严重程度 | 处理建议 |
|----------|------|----------|----------|
| R001 | ROI < 1 | 高 | 停投，重做素材 |
| R002 | ROI 1~1.5 | 中 | 观察3天，优化出价和人群 |
| R003 | CTR < 2% | 中 | 内容吸引力不足，优化封面和标题 |
| R004 | 购物车到成交转化率 < 5% | 中 | 落地页/价格有问题 |
| R005 | 消耗>300且未回本 | 高 | 暂停，分析原因 |
| R006 | 2秒跳出率 > 50% | 高 | 钩子质量差，重做前3秒 |

### 内容异常规则

| 规则编号 | 条件 | 严重程度 | 处理建议 |
|----------|------|----------|----------|
| C001 | 2秒跳出率 > 50% | 高 | 前3秒钩子需重做 |
| C002 | 完播率 < 10% | 高 | 内容节奏或选题有问题 |
| C003 | 评论负面占比 > 30% | 中 | 产品或内容需调整 |

## 四、5条视频的复盘结论

### V001 - 上班族40秒早餐果汁

| 指标 | 数值 | 判断 |
|------|------|------|
| 播放量 | 12,000 | 中等 |
| 2秒跳出率 | 38% | 正常 |
| 完播率 | 15% | 达标 |
| ROI | 2.37 | 良好 |
| 购物车点击率 | 0.6% | 正常 |
| 成交转化率 | 8.9% | 良好 |

**结论**：表现良好，可继续投放。评论集中问清洗问题，建议在脚本中增加清洗演示环节。

### V002 - 健身饮品

| 指标 | 数值 | 判断 |
|------|------|------|
| 播放量 | 8,000 | 偏低 |
| 2秒跳出率 | 51% | **异常** |
| 完播率 | 9% | **异常** |
| ROI | 0.89 | **亏损** |
| 购物车点击率 | 0.35% | 偏低 |
| 成交转化率 | 5.7% | 正常 |

**结论**：**停投重做**。前3秒钩子偏弱导致跳出率高，点击偏低说明内容吸引力不足。建议：优化开头钩子，增加运动场景吸引力，重新制作脚本。

### V003 - 宿舍饮品

| 指标 | 数值 | 判断 |
|------|------|------|
| 播放量 | 20,000 | **最高** |
| 2秒跳出率 | 29% | **最优** |
| 完播率 | 21% | **最优** |
| ROI | 6.41 | **最优** |
| 购物车点击率 | 0.88% | 良好 |
| 成交转化率 | 8.2% | 良好 |

**结论**：**继续放量**，表现最优。收藏较高说明用户有购买意愿，评论关注价格和容量，建议准备宿舍场景2.0版本，突出性价比。

### V004 - 家庭饮品

| 指标 | 数值 | 判断 |
|------|------|------|
| 播放量 | 5,500 | 偏低（自然流量） |
| 2秒跳出率 | 42% | 偏高 |
| 完播率 | 12% | 偏低 |
| ROI | - | 无投流 |
| 购物车点击率 | 0.69% | 正常 |
| 成交转化率 | 8.3% | 良好 |

**结论**：自然流量样本较小，但转化表现可参考。建议小预算测试验证转化后考虑放量。

### V005 - 办公室下午茶替代奶茶

| 指标 | 数值 | 判断 |
|------|------|------|
| 播放量 | 15,000 | 良好 |
| 2秒跳出率 | 34% | 正常 |
| 完播率 | 18% | 良好 |
| ROI | 2.45 | 良好 |
| 购物车点击率 | 0.8% | 良好 |
| 成交转化率 | 6.9% | 正常 |

**结论**：购物车点击不错但成交未明显放大。建议优化购物车落地页，检查价格竞争力，考虑增加限时优惠刺激转化。

## 五、AI 复盘提示词

```
你是一位短视频电商数据分析师。请根据以下数据生成{period}复盘报告。

数据汇总：
{data_summary}

请输出复盘报告，包含：
1. highlights: 本期亮点
2. problems: 主要问题
3. top_performing_videos: 表现最好的视频及原因
4. underperforming_videos: 表现最差的视频及原因
5. optimization_priorities: 优先优化方向
6. action_items: 具体动作清单（含负责人和截止时间）

要求：
- 不能只说"数据好/不好"，必须讲清判断依据
- 每个优化建议必须可执行
- 基于数据做判断，不凭感觉
```
