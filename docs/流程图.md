# 任务1：业务流程拆解与系统方案

## 一、整体业务流程

```
选品 → 内容拆解 → 秒级脚本 → 视频制作 → 发布/投流 → 数据复盘 → 知识库沉淀
  ↑                                                                              ↓
  └──────────────────────── 经验反馈闭环 ←──────────────────────────────────────────┘
```

## 二、各节点详细流程

### 1. 选品板块

| 项目 | 说明 |
|------|------|
| **输入** | 市场热点、竞品数据、供应链商品池 |
| **处理** | 商品调研 → 卖点提取 → 人群匹配 → 风险词筛查 → 评分打分 |
| **输出** | 商品库记录（含评分、标签、优先级） |
| **责任人** | 选品运营（张三） |
| **状态流转** | 待评估 → 已选品 → 已淘汰 |
| **关键字段** | 商品编号、名称、价格、佣金、热度、口碑、卖点、痛点、风险词、选品评分 |
| **异常情况** | 风险词命中、口碑低于4.5分、佣金过低 |
| **数据去向** | → 内容拆解表（关联商品ID） |

### 2. 内容板块

| 项目 | 说明 |
|------|------|
| **输入** | 已选品商品 + 竞品爆款视频 |
| **处理** | 爆款拆解 → 钩子分析 → 结构提炼 → 二创角度设计 |
| **输出** | 内容拆解记录（含钩子、结构、转化点、二创角度） |
| **责任人** | 内容策划（李四） |
| **状态流转** | 待拆解 → 已拆解 → 已二创 |
| **关键字段** | 内容编号、对标链接、钩子、场景、人群、结构、转化点、二创角度 |
| **异常情况** | 对标内容违规、二创角度雷同 |
| **数据去向** | → 脚本分镜表（关联内容ID） |

### 3. 脚本板块

| 项目 | 说明 |
|------|------|
| **输入** | 商品卖点 + 内容方向 |
| **处理** | AI生成脚本 → 秒级分镜拆解 → 人工审核 → 提示词输出 |
| **输出** | 秒级分镜脚本（含旁白、字幕、画面描述、AI提示词） |
| **责任人** | 脚本编导（王五） |
| **状态流转** | 待生成 → 已生成 → 待审核 → 已通过/已驳回 |
| **关键字段** | 脚本编号、镜头时间、画面描述、旁白、字幕、镜头运动、AI提示词、审核状态 |
| **异常情况** | AI生成质量不达标、合规词命中 |
| **数据去向** | → 视频生产表（关联脚本ID） |

### 4. 视频制作板块

| 项目 | 说明 |
|------|------|
| **输入** | 审核通过的脚本 + 分镜 |
| **处理** | 素材准备 → AI生成/剪映精剪 → 质检 → 版本迭代 |
| **输出** | 成片 + 质检报告 |
| **责任人** | 剪辑师（赵六/钱七） |
| **状态流转** | 待准备 → 制作中 → 质检中 → 已完成 |
| **关键字段** | 视频编号、素材状态、生成工具、版本、质检项、发布状态 |
| **异常情况** | 素材缺失、质检不通过、版本反复修改 |
| **数据去向** | → 投流数据表（关联视频ID） |

### 5. 投流板块

| 项目 | 说明 |
|------|------|
| **输入** | 已发布视频 + 千川投流计划 |
| **处理** | 创建计划 → 数据监控 → 异常提醒 → 复盘分析 → 决策（放量/优化/停投） |
| **输出** | 投流数据记录 + 复盘建议 |
| **责任人** | 投流运营 |
| **状态流转** | 待投放 → 投放中 → 已暂停 → 已结案 |
| **关键字段** | 计划名称、消耗、展现、点击、CTR、购物车点击、成交金额、订单数、ROI、异常判断 |
| **异常情况** | ROI<1、2秒跳出率>50%、消耗过快 |
| **数据去向** | → 数据复盘表 + 知识库沉淀 |

### 6. 数据复盘板块

| 项目 | 说明 |
|------|------|
| **输入** | 商品、内容、视频、投流数据 |
| **处理** | 数据汇总 → 指标计算 → 问题归因 → 优化建议 → AI自动复盘 |
| **输出** | 复盘报告 + 下一步动作清单 |
| **责任人** | 运营负责人 |
| **状态流转** | 待复盘 → 分析中 → 已完成 |
| **关键字段** | 复盘周期、各维度表现、问题归因、优化动作、负责人、截止时间 |
| **异常情况** | 数据缺失、归因不明确 |
| **数据去向** | → 知识库沉淀 + 下一轮选品/内容优化 |

### 7. 知识库沉淀

| 项目 | 说明 |
|------|------|
| **输入** | 各板块经验、数据、模板 |
| **处理** | 分类整理 → 标准化 → 版本管理 → 效果追踪 |
| **输出** | 知识库条目（卖点库、内容库、脚本库、提示词库、话术库、SOP） |
| **责任人** | 各模块负责人 + 运营负责人 |
| **关键字段** | 知识编号、分类、来源、适用场景、内容摘要、提示词版本、使用效果 |

## 三、优先级清单

| 优先级 | 环节 | 说明 |
|--------|------|------|
| P0-先用表格提效 | 商品库、内容拆解、脚本分镜 | 结构化数据，适合多维表格管理 |
| P0-先用表格提效 | 投流数据、复盘表 | 数据驱动决策，需要统计分析 |
| P1-适合智能体化 | AI脚本生成、视频质检 | 重复性高，规则明确，适合AI自动化 |
| P1-适合智能体化 | 投流复盘分析 | 数据量大，分析维度多，AI辅助效率高 |
| P2-后续优化 | 客服话术生成、选品评分 | 需要积累数据后才能发挥价值 |
