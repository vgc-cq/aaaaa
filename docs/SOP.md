# 任务6：知识库沉淀与团队 SOP

## 一、知识库分类结构

### 1. 商品卖点库
- **用途**：沉淀每个商品的核心卖点、目标人群、痛点、风险词
- **更新频率**：每次选品完成后
- **维护人**：选品运营

### 2. 爆款内容库
- **用途**：收藏和拆解竞品爆款视频的结构、钩子、转化点
- **更新频率**：每周至少更新3条
- **维护人**：内容策划

### 3. 脚本库
- **用途**：沉淀高转化脚本模板、秒级分镜结构
- **更新频率**：每次脚本审核通过后
- **维护人**：脚本编导

### 4. 提示词库
- **用途**：管理AI生成图片/视频/脚本的提示词模板
- **更新频率**：每次提示词优化后
- **维护人**：技术/内容

### 5. 投流复盘库
- **用途**：沉淀投流经验、异常判断规则、优化策略
- **更新频率**：每次复盘完成后
- **维护人**：投流运营

### 6. 复盘经验库
- **用途**：沉淀投流复盘中被人工"认可"的结论与优化动作
- **更新频率**：每次复盘标记"认可"后自动沉淀
- **维护人**：投流运营/运营负责人

### 7. 员工SOP
- **用途**：各岗位的标准操作流程
- **更新频率**：流程变更时
- **维护人**：运营负责人

## 二、新人操作SOP：短视频电商运营系统使用指南

### 适用对象
新入职的运营人员、内容策划、剪辑师

### 系统入口
- 后端API：`http://localhost:8080/docs` （Swagger文档）
- 前端界面：`http://localhost:3000`

---

### SOP-1：新增商品到商品库

**步骤**：
1. 打开前端 → 点击左侧菜单"商品库"
2. 点击右上角"新增商品"按钮
3. 填写必填字段：
   - 商品编号：格式 P001、P002...
   - 商品名称：完整商品名
4. 填写选填字段：类目、价格区间、目标人群、卖点、痛点
5. 设置选品评分（0-100分）
6. 选择状态：待评估/已选品/已淘汰
7. 指定负责人
8. 点击"保存"

**注意事项**：
- 风险词字段必须填写，避免内容违规
- 评分标准：80分以上建议选品，60-80观察，60以下淘汰
- 同一商品不可重复编号

**验收标准**：
- [ ] 商品编号唯一
- [ ] 必填字段完整
- [ ] 风险词已填写
- [ ] 负责人已指定

---

### SOP-2：拆解爆款内容

**步骤**：
1. 在抖音/快手找到对标视频
2. 打开前端 → "内容拆解" → "新增内容"
3. 填写：
   - 内容编号：C001、C002...
   - 对标链接：视频URL
   - 开头钩子：前3秒的话术
   - 场景：视频拍摄场景
   - 人群：目标受众
   - 内容结构：开头-中间-结尾的结构描述
   - 转化点：引导购买的话术/动作
   - 可二创角度：可以改编的方向
4. 关联适配商品（选择商品ID）
5. 指定拆解人
6. 保存

**注意事项**：
- 钩子必须是原话，不要概括
- 结构描述要具体到秒级
- 风险点必须标注

**验收标准**：
- [ ] 钩子为原话引用
- [ ] 结构描述包含时间节点
- [ ] 至少列出2个二创角度
- [ ] 已关联商品

---

### SOP-3：生成脚本分镜

**步骤**：
1. 打开前端 → "脚本分镜"
2. 在关联商品框选择商品库里的商品
3. 旁边的"关联内容"框会自动带出该商品对应的内容拆解记录
4. 点击"生成脚本"，DeepSeek 基于拆解要点生成 20 秒内完整秒级分镜
5. 展开脚本查看每个分镜（画面描述、旁白、字幕、AI 提示词），最多显示 3 行，完整内容进详情查看
6. 人工审核脚本，修改不合适的部分，设置审核状态

**注意事项**：
- AI生成的内容必须人工审核
- 质检评分低于80分建议重新生成
- 合规性检查：不能有夸大宣传、医疗功效等
- 同一商品同一批镜头会归到同一个脚本分组，方便整体管理

**验收标准**：
- [ ] 脚本包含秒级分镜
- [ ] 每个分镜有画面描述和旁白
- [ ] AI提示词可用于文生图/视频
- [ ] 质检评分≥80或已人工修改
- [ ] 无违规词

---

### SOP-4：视频制作与发布

**步骤**：
1. 打开前端 → "视频任务"
2. 选择关联商品，自动带出对应脚本分镜
3. 点击"生成视频"，系统调用通义万相 Wan2.7 把整组分镜合成为一支视频（20 秒以内）
4. 在"生成进度"查看生成状态（轮询更新，约几分钟）
5. 生成成功后查看视频详情（播放器预览），填写质检项与发布平台
6. 发布平台可一键跳转到抖音/快手等创作者上传页

**注意事项**：
- 质检项必须逐项打分
- 版本号递增（v1, v2...）
- 发布前检查字幕、音频、画面
- 生成中的视频不允许修改基本信息，只能重新生成参数

**验收标准**：
- [ ] 视频时长与脚本一致
- [ ] 质检项已填写
- [ ] 审核通过后才能发布

---

### SOP-5：投流与复盘

**步骤**：
1. 在千川创建投流计划
2. 打开前端 → "投流数据" → 手动新增，或切到"一键导入"页签上传 Excel（表头自动识别、按 V 编号关联视频）
3. 每日填写/导入：消耗、展现、点击、购物车点击、成交金额、订单数
4. 系统自动计算：CTR、ROI，并自动触发数据复盘智能体
5. 打开"数据复盘"→ 点"开始复盘"查看节点卡片运行过程与结论
6. 根据智能体的评级、决策与优化建议调整投放策略

**判断标准**：
- ROI > 3：继续放量
- ROI 1.5-3：小幅优化
- ROI 1-1.5：观察调整
- ROI < 1：考虑停投

**验收标准**：
- [ ] 每日更新投流数据
- [ ] 异常已标注原因
- [ ] 复盘建议已填写

---

### SOP-6：使用智能体

**步骤**：
1. 打开前端 → "数据复盘"
2. 点击"开始复盘"（处理全部未复盘投流数据；勾选"强制重新复盘（含已复盘）"则全部重跑）
3. 观察五张节点卡片逐一点亮：读取数据 → 指标计算 → AI 复盘 → 写回建议 → 记录日志
4. 查看节点卡片与"最近复盘运行记录"（点行尾箭头展开该次运行结果）
5. 在下方"复盘记录表"里对结论做人工确认：
   - 状态改为"认可"：沉淀为知识库"已生效"知识，下次复盘自动参考
   - 状态改为"不认可"：写入经验记忆，避免以后输出类似结论
6. 根据智能体结论执行投放决策（放量/优化/停投）

**注意事项**：
- AI输出仅供参考，需人工判断
- 复盘数据会按未复盘状态自动触发，也可手动"开始复盘"
- 认可得越多，智能体下次结论越贴近你的判断习惯

### 常见错误

| 错误 | 原因 | 解决方案 |
|------|------|----------|
| 商品编号重复 | 手动填写冲突 | 使用P001格式递增 |
| 脚本无关联商品 | 忘记填写外键 | 创建时检查关联字段 |
| 投流数据ROI异常 | 消耗为0 | 确保消耗>0再计算ROI |
| 复盘长时间不返回 | DeepSeek 响应慢/限流 | 已加 60 秒超时兜底，可稍后重试 |
| 视频生成失败 | 通义万相任务异常 | 查看生成状态详情，重新生成 |
| 视频状态未更新 | 忘记修改状态 | 发布后及时更新状态 |

---

### 复盘归档流程

1. 投流数据录入/导入后，数据复盘智能体自动复盘未处理数据
2. 在"数据复盘"页点"开始复盘"跑全量复盘，查看节点卡片与运行结果
3. 逐条确认结论：认可的标记为"认可"（自动沉淀知识库），不认可的标记"不认可"
4. 复盘记录表里补充/修正问题归因与优化动作
5. 知识库中的"复盘经验"分类沉淀本周已验证结论
6. 更新相关SOP
