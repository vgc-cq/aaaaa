# 任务6：知识库沉淀与团队 SOP

## 一、知识库分类结构

### 1. 商品卖点库
- **用途**：沉淀每个商品的核心卖点、目标人群、痛点、风险词
- **更新频率**：每次选品完成后
- **维护人**：选品运营

### 2. 爆款内容库
- **用途**：收藏和拆解竞品爆款视频的结构、钩子、转化点
- **更新频率**：每周至少更新3条
- **维护人**：内容策划

### 3. 脚本库
- **用途**：沉淀高转化脚本模板、秒级分镜结构
- **更新频率**：每次脚本审核通过后
- **维护人**：脚本编导

### 4. 提示词库
- **用途**：管理AI生成图片/视频/脚本的提示词模板
- **更新频率**：每次提示词优化后
- **维护人**：技术/内容

### 5. 投流复盘库
- **用途**：沉淀投流经验、异常判断规则、优化策略
- **更新频率**：每次复盘完成后
- **维护人**：投流运营

### 6. 客服话术库
- **用途**：沉淀高频问题的标准回复话术
- **更新频率**：每周更新
- **维护人**：客服主管

### 7. 员工SOP
- **用途**：各岗位的标准操作流程
- **更新频率**：流程变更时
- **维护人**：运营负责人

## 二、新人操作SOP：短视频电商运营系统使用指南

### 适用对象
新入职的运营人员、内容策划、剪辑师

### 系统入口
- 后端API：`http://localhost:8000/docs` （Swagger文档）
- 前端界面：`http://localhost:3000`

---

### SOP-1：新增商品到商品库

**步骤**：
1. 打开前端 → 点击左侧菜单"商品库"
2. 点击右上角"新增商品"按钮
3. 填写必填字段：
   - 商品编号：格式 P001、P002...
   - 商品名称：完整商品名
4. 填写选填字段：类目、价格区间、目标人群、卖点、痛点
5. 设置选品评分（0-100分）
6. 选择状态：待评估/已选品/已淘汰
7. 指定负责人
8. 点击"保存"

**注意事项**：
- 风险词字段必须填写，避免内容违规
- 评分标准：80分以上建议选品，60-80观察，60以下淘汰
- 同一商品不可重复编号

**验收标准**：
- [ ] 商品编号唯一
- [ ] 必填字段完整
- [ ] 风险词已填写
- [ ] 负责人已指定

---

### SOP-2：拆解爆款内容

**步骤**：
1. 在抖音/快手找到对标视频
2. 打开前端 → "内容拆解" → "新增内容"
3. 填写：
   - 内容编号：C001、C002...
   - 对标链接：视频URL
   - 开头钩子：前3秒的话术
   - 场景：视频拍摄场景
   - 人群：目标受众
   - 内容结构：开头-中间-结尾的结构描述
   - 转化点：引导购买的话术/动作
   - 可二创角度：可以改编的方向
4. 关联适配商品（选择商品ID）
5. 指定拆解人
6. 保存

**注意事项**：
- 钩子必须是原话，不要概括
- 结构描述要具体到秒级
- 风险点必须标注

**验收标准**：
- [ ] 钩子为原话引用
- [ ] 结构描述包含时间节点
- [ ] 至少列出2个二创角度
- [ ] 已关联商品

---

### SOP-3：AI生成脚本

**步骤**：
1. 打开前端 → "AI工作流"
2. 填写商品信息（或从商品库复制）
3. 点击"运行完整工作流"
4. 等待AI分析完成（约30秒）
5. 查看结果：
   - 卖点分析 → 确认核心卖点
   - 内容角度 → 选择最优角度
   - 脚本分镜 → 检查每秒内容
   - 质检报告 → 查看评分和问题
6. 人工审核脚本，修改不合适的部分
7. 将审核通过的脚本保存到"脚本分镜表"

**注意事项**：
- AI生成的内容必须人工审核
- 质检评分低于80分建议重新生成
- 合规性检查：不能有夸大宣传、医疗功效等

**验收标准**：
- [ ] 脚本包含秒级分镜
- [ ] 每个分镜有画面描述和旁白
- [ ] AI提示词可用于文生图/视频
- [ ] 质检评分≥80或已人工修改
- [ ] 无违规词

---

### SOP-4：视频制作与发布

**步骤**：
1. 在"脚本分镜表"找到审核通过的脚本
2. 打开前端 → "视频任务" → "新增视频"
3. 填写：
   - 视频编号：V001、V002...
   - 关联脚本ID
   - 生成工具：剪映/可灵/AI
   - 剪辑负责人
4. 按脚本分镜制作视频
5. 完成后填写质检项（各维度评分）
6. 提交审核 → 发布

**注意事项**：
- 质检项必须逐项打分
- 版本号递增（v1, v2...）
- 发布前检查字幕、音频、画面

**验收标准**：
- [ ] 视频时长与脚本一致
- [ ] 质检项已填写
- [ ] 审核通过后才能发布

---

### SOP-5：投流与复盘

**步骤**：
1. 在千川创建投流计划
2. 打开前端 → "投流数据" → 新增数据
3. 每日填写：消耗、展现、点击、购物车点击、成交金额、订单数
4. 系统自动计算：CTR、ROI
5. 查看"仪表盘"的视频排名和异常提醒
6. 根据系统建议调整投放策略

**判断标准**：
- ROI > 3：继续放量
- ROI 1.5-3：小幅优化
- ROI 1-1.5：观察调整
- ROI < 1：考虑停投

**验收标准**：
- [ ] 每日更新投流数据
- [ ] 异常已标注原因
- [ ] 复盘建议已填写

---

### SOP-6：使用智能体

**步骤**：
1. 打开前端 → "智能体"
2. 选择智能体类型（投流复盘/选品分析/脚本生成/视频质检/客服话术）
3. 填写输入数据
4. 点击运行按钮
5. 查看AI输出结果
6. 人工确认后执行

**注意事项**：
- AI输出仅供参考，需人工判断
- 复杂情况需结合多个智能体分析
- 记录AI分析的效果，持续优化提示词

---

### 常见错误

| 错误 | 原因 | 解决方案 |
|------|------|----------|
| 商品编号重复 | 手动填写冲突 | 使用P001格式递增 |
| 脚本无关联商品 | 忘记填写外键 | 创建时检查关联字段 |
| 投流数据ROI异常 | 消耗为0 | 确保消耗>0再计算ROI |
| AI工作流超时 | API响应慢 | 检查网络和API配置 |
| 视频状态未更新 | 忘记修改状态 | 发布后及时更新状态 |

### 复盘归档流程

1. 每周日晚填写"数据复盘表"
2. 汇总本周所有视频的表现数据
3. 分析问题归因
4. 制定下周优化动作
5. 将经验沉淀到知识库
6. 更新相关SOP
